# شطر · shatr

[English](README.md) · **العربية**

**انشُر موقعًا عربيًّا كاملًا لقصيدتك — سريعًا وميسورَ الوصول — انطلاقًا من النصّ
وحده.** تكتب القصيدة (شطرٌ في كلّ سطر، مضبوطةً بالكامل) فيولِّد `shatr` موقعًا
أنيقًا من صفحةٍ واحدة، بضبطٍ تلقائيٍّ بالكشيدة (التطويل)، ووضعٍ ليليّ، وتكبيرٍ
للخطّ، وشريطٍ سفليٍّ للجوّال، وتحسينٍ كاملٍ لمحرّكات البحث مع البيانات المنظَّمة،
وتطبيقِ ويبٍ تقدّميّ (PWA — قابلٍ للتثبيت، يعمل دون اتّصال، بشاشة بدءٍ مخصّصة)،
وبناءٍ ميسورِ الوصول بدرجة Lighthouse كاملة. ويَنشُر نفسه على GitHub Pages مع كلّ
دفعة (push).

وهو المحرّك وراء [hmittou.benjelloun.dev](https://hmittou.benjelloun.dev)،
مُعمَّمًا لتنال أيُّ قصيدةٍ المعاملةَ نفسها.

---

## البداية السريعة (للبشر)

1. اضغط **“Use this template” ← Create a new repository** (مستودعٌ لكلّ قصيدة).
2. حرِّر **ملفّين**:
   - **`content/poem.txt`** — قصيدتك، شطرٌ في كلّ سطر (انظر [AUTHORING.md](AUTHORING.md)).
   - **`content/poem.config.json`** — العنوان، الشاعر، النطاق، الوصف، الروابط.
3. **احفظ (Commit).** يبني إجراءُ GitHub المُضمَّن الموقعَ ويَنشُره على GitHub Pages
   تلقائيًّا. فعِّله مرّةً واحدة: **Settings ← Pages ← Source: GitHub Actions**.
4. (اختياريّ) وجِّه **نطاقًا خاصًّا** + **Cloudflare** إليه — انظر [DEPLOY.md](DEPLOY.md).

لا تحتاج إلى الطرفيّة (terminal) البتّة: حرِّر الملفّين في محرّر GitHub على الويب،
ثمّ احفظ، وانتهى الأمر.

### أو عبر سطر الأوامر (CLI)

<div dir="ltr">

```bash
npm install
npx shatr init      # تفاعليًّا: يُنشئ content/poem.config.json
npx shatr check     # يتحقّق من القصيدة + الإعدادات (دون بناء)
npx shatr build     # يكتب dist/
npx shatr preview   # يبني ويَخدِم على http://localhost:8080
npx shatr pdf       # يصدّر ملفّات PDF للطباعة (A4 + كتيّب للجوّال) إلى content/
```

</div>

يعمل `shatr init` تفاعليًّا *ومن* المُدخَل المُمرَّر (scriptable / مناسبٌ للذكاء
الاصطناعيّ).

### أو عبر الاستوديو المرئيّ

<div dir="ltr">

```bash
npx shatr studio   # ثمّ افتح http://localhost:8080/studio/
```

</div>

اكتب القصيدة واملأ النموذج، وعايِن **الكشيدة مباشرةً**، ثمّ نزِّل `poem.txt`
و`poem.config.json` لتضعهما في مستودعك. ويُرشدك الاستوديو خطوةً خطوة إلى النشر على
GitHub Pages **الخاصّ بك**.

## ما الذي تحصل عليه (جاهزًا)

- **ضبطٌ بالكشيدة** — يُمدّ شطرا كلّ بيتٍ إلى عرضٍ متساوٍ بقياسٍ على لوحةٍ
  (canvas) دون أيّ إعادة تخطيط (zero reflow).
- **وضعٌ ليليّ** (محفوظ)، و**تكبيرٌ للخطّ** (للجلسة فقط، يُعاد ضبطه عند التحديث أو
  الدوران)، و**شريطٌ سفليٌّ** للجوّال يختفي تلقائيًّا، و**شريط تقدّمٍ** للقراءة،
  وتنقّلٌ سلسٌ داخل القصيدة.
- **سمات (Themes)**: سماتٌ لونيّةٌ بسطرٍ واحد (`stone`، `sepia`، `midnight`،
  `rawda`) بلوحاتٍ نهاريّةٍ/ليليّةٍ متناسقةٍ مع ألوان التطبيق —
  `"theme": { "preset": "sepia" }`.
- **تحسين محرّكات البحث (SEO)**: العنوان والوصف والكلمات المفتاحيّة، وOpen Graph
  وTwitter (صورةٌ واحدةٌ بمقاسٍ صحيح لتعمل معايناتُ واتساب وفيسبوك)، وبياناتُ
  `CreativeWork`/`Poem` المنظَّمة (**JSON-LD**)، و`sitemap.xml`، و`robots.txt`،
  والرابط القانونيّ (canonical).
- **تطبيق ويب تقدّميّ (PWA)**: بيانُ تطبيقٍ (manifest)، وعامل خدمةٍ (يعمل دون
  اتّصال)، قابلٌ للتثبيت، بشاشة بدءٍ مخصّصة.
- **الأداء وإتاحة الوصول**: خطٌّ عربيٌّ مُجزَّأٌ مُستضافٌ ذاتيًّا مع
  `font-display:swap` وتحميلٍ مُسبَق، وسياسةُ أمانِ محتوًى صارمة (CSP)، ورابطُ
  تخطٍّ، ووسومُ ARIA، ودعمُ تقليل الحركة، واتّجاهُ RTL، وورقةُ أنماطٍ للطباعة.
- **تحقّقٌ ذكيّ**: يفشل البناء عند شطرٍ فردٍ بلا قرين، ويُنبِّه على الأسطر التي
  تبدو ناقصةَ الضبط.

## لوكلاء الذكاء الاصطناعيّ

يَشحَن هذا المستودع إرشاداتٍ يلتقطها تلقائيًّا كلٌّ من Claude Code وGemini CLI
وOpenAI Codex وGitHub Copilot وCursor — مرجعُها **[AGENTS.md](AGENTS.md)** (وتشير
إليه `CLAUDE.md` و`GEMINI.md` و`.github/copilot-instructions.md` و`.cursor/rules/`).
الخلاصة: تُحرّر ملفّين فقط — `content/poem.txt` (شطرٌ في كلّ سطر، ضبطٌ كامل، `##`
لبدء بابٍ جديد، `#` للتعليق) و`content/poem.config.json` (مخطَّطُه في `schema/`).
**لا تختلق نصَّ القصيدة ولا تشكيلها ولا تُعدِّلهما** — يأتي النصُّ من المؤلِّف أو من
مصدرٍ موثَّق ويُنقل حرفيًّا؛ وكلُّ بابٍ يحتاج عددًا **زوجيًّا** من الأشطار. تحقَّق
بـ`npm run check`، وابنِ واختبِر بـ`npm test`.

## بنية المستودع

<div dir="ltr">

```
content/      ← تحرّر هذا (poem.txt + poem.config.json)
engine/       ← المحرّك (القالب، CSS، app.js، sw، الأيقونات) — اتركه
scripts/      ← build.mjs (المولِّد) + validate.mjs
schema/       ← مخطَّط JSON لـ poem.config.json
fonts/        ← خطّ أميري المُجزَّأ (عربيّ)
dist/         ← ناتج البناء (مُولَّد؛ لا يُحفظ في git)
```

</div>
